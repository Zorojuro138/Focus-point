FocusPilot for Windows

1. Extract the entire ZIP to a folder.
2. Keep FocusPilot.exe beside the _internal folder.
3. Double-click FocusPilot.exe.
4. To get goal-aware browser checks, open chrome://extensions in Chrome or
   edge://extensions in Edge, enable Developer mode, and choose "Load unpacked".
   Select the _internal\browser-extension folder beside FocusPilot.exe.

On first launch, read the privacy notice and choose whether to consent. Activity
tracking starts only when you start a focus session. FocusPilot stores data
locally on this device; data is not shared with other devices. With AI enabled,
the session goal, page title, and page URL path (without query or fragment) are
sent to Google's Gemini Free API. No screenshots or page contents are sent.

This portable build is for Windows 10/11 x64. Do not run FocusPilot.exe from
inside the ZIP without extracting the complete folder first.
